# Quy trình & Tổ chức

## Giai đoạn hiện tại: Thử nghiệm

### Quy trình làm video đơn giản

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   Ý tưởng   │ →  │    Quay     │ →  │    Edit     │ →  │    Đăng     │ →  │  Phân tích  │
│  (5-10 phút)│    │ (tùy content)│   │ (15-30 phút)│    │   TikTok    │    │   Data      │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### Checklist trước khi đăng

- [ ] Video có hook trong 1-3 giây đầu?
- [ ] Âm thanh rõ ràng?
- [ ] Có caption/text trên video?
- [ ] Đã chọn nhạc trending (nếu phù hợp)?
- [ ] Hashtag phù hợp?

## Tổ chức file (đề xuất)

```
/creator
├── .kiro/steering/     # Tài liệu hướng dẫn (đang ở đây)
├── /ideas/             # Ý tưởng video, ghi chú
├── /scripts/           # Kịch bản (nếu có)
├── /analytics/         # Ghi chép data, insights
└── /learnings/         # Bài học rút ra, điều cần cải thiện
```

## Theo dõi Performance

### Metrics quan trọng trên TikTok
- **Views** - Số lượt xem
- **Watch time** - Thời gian xem trung bình
- **Completion rate** - % người xem hết video
- **Engagement** - Like, comment, share, save
- **Traffic source** - Người xem đến từ đâu (FYP, following, search...)

## Lịch đăng bài (gợi ý)

- Giai đoạn thử nghiệm: **3-5 video/tuần** (hoặc hơn nếu có thời gian)
- Giờ đăng tốt: Thử nghiệm nhiều khung giờ, theo dõi data
- Không cần hoàn hảo, cần consistent!
